# Security Policy

## Supported Versions

Only the latest release version on `main` is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4   | :x:                |

## Reporting a Vulnerability

Clipboard management software handles sensitive information copied by the user, such as authentication tokens, passwords, and personal text. We take security seriously.

If you believe you have found a security vulnerability in Copie:

1. **Do not open a public issue.**
2. Send an email to the maintainer at `ducna0412@gmail.com` with the subject `[SECURITY] Copie Vulnerability Report`.
3. Provide a detailed description of the vulnerability, steps to reproduce, and any relevant proof of concept.

You will receive an acknowledgment within 48 hours. We appreciate your efforts to responsibly disclose findings and help keep Copie users safe.
